Catatan Implementasi

Bagaimana Scraping / GraphQL Bekerja?

Backend menggunakan pendekatan scraping halaman publik atau GraphQL endpoint internal jika tersedia. Data yang diekstrak dikembalikan dalam format JSON bersih. Untuk produksi, disarankan menggunakan layanan proxy atau API pihak ketiga yang stabil, karena endpoint sosial media sering berubah.
